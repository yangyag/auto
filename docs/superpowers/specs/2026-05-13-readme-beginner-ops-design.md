# README 초보 운영자 보강 설계

## 목표

`README.md`를 초보 운영자가 일상 운영에 바로 참고할 수 있게 보강한다. 현재 README는 전략과 구현 설명이 중심이므로, 운영자가 처음 열었을 때 실행, 중지, 로그, 상태 확인, 그리드 반영, 위험 명령을 먼저 찾을 수 있게 한다.

## 대상 독자

주요 독자는 저장소 접근 권한은 있지만 전체 전략 구현을 아직 깊게 이해하지 못한 운영자다. 이 독자는 다음 질문에 빠르게 답을 찾고 싶어 한다.

- 봇이 지금 실행 중인가?
- 어떻게 시작하거나 멈추는가?
- 로그는 어디서 보는가?
- 잔고와 현재 그리드 상태는 어떻게 확인하는가?
- `grid.properties`를 바꾼 뒤 무엇을 실행하는가?
- 어떤 명령은 위험해서 조심해야 하는가?

## 범위

수정 대상은 `README.md` 하나로 제한한다.

README 상단에 초보 운영자용 섹션을 추가한다. 기존 파일 구성, 전략 개요, 상태 모델, 매수/매도 로직, WebSocket, 그리드 생성, 설정 설명은 유지한다.

범위 밖:

- 코드, 스크립트, 런타임 동작, `.env`, `grid.properties`, DB migration 변경
- `docs/setup.md`, `docs/operations.md`, `docs/quick-commands.md` 재작성
- 기존 문서에 없는 새 운영 명령 추가

## 내용 설계

README 상단에 다음 내용을 추가한다.

1. 문서 읽는 순서 안내
   - 일상 운영자는 새 빠른 시작 섹션부터 본다.
   - 최초 설치는 `docs/setup.md`를 본다.
   - 자세한 운영 절차와 명령 목록은 `docs/operations.md`, `docs/quick-commands.md`를 본다.

2. `초보 운영자 빠른 시작`
   - 기준 작업 위치를 명시한다.
   - 봇 실행 여부 확인, 로그 확인, 그리드 상태 확인, 잔고 확인, 시작, 종료 명령을 제공한다.
   - Python 명령은 프로젝트 가상환경인 `.venv/bin/python`을 우선 사용한다.

3. `grid.properties 수정 후 기본 흐름`
   - 라이브 설정 변경 전에는 봇을 멈추라고 안내한다.
   - DB 그리드 반영과 상태 확인 명령을 제공한다.
   - 이 경로는 DB 그리드 반영이며, 라이브 리셋과 예산 조정은 별도 운영 경로라고 설명한다.

4. `위험 명령`
   - `scripts/reset_krw_btc_live.py`는 KRW-BTC 미체결 주문 취소, BTC 전량 시장가 매도, 그리드 재반영을 수행하므로 위험 명령으로 표시한다.
   - `scripts/adjust_budget_live.py`는 기존 보유 물량을 즉시 줄이지 않는 soft adjust라고 설명한다.
   - 자세한 절차는 기존 운영 문서로 연결한다.

5. `문제가 생기면 먼저 볼 것`
   - 최신 로그
   - `scripts/show_grid_state.py`
   - `main.py balance`
   - `.env`와 PostgreSQL 설정

## 문체

README 본문과 같은 한국어 설명체를 사용한다. 명령은 복사해서 바로 실행할 수 있게 코드 블록으로 제공한다.

`docs/quick-commands.md`의 모든 내용을 중복하지 않고, README는 입구 역할만 하도록 간결하게 유지한다.

## 완료 기준

- README 상단에서 초보 운영자가 일상 운영 명령을 찾을 수 있다.
- 실행, 종료, 로그, 상태, 잔고, 그리드 반영, 리셋 주의, 예산 조정 주의가 포함된다.
- 기존 참고 문서 링크는 유지된다.
- 런타임 코드와 설정 파일은 변경하지 않는다.
- Markdown에 미완성 문구나 자리표시자가 없다.

## 자체 검토

- 자리표시자 없음.
- 범위는 README 단일 문서 변경으로 제한됨.
- 위험 명령은 명확히 위험하다고 표시하고, 세부 절차는 기존 운영 문서로 위임함.
